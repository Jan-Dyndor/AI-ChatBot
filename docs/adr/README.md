# Architecture Decision Records

Architecture Decision Records (ADRs) explain the important technical decisions
in this project, including their context, evidence, trade-offs, and current
status. They make it possible to understand not only *what* the architecture
is, but *why* it was chosen.

| ADR | Status | Decision |
| --- | --- | --- |
| [0001](0001-native-ollama-outside-docker-compose.md) | Accepted | Run Ollama natively instead of in Docker Compose. |

New ADRs should use the next sequential number and follow the same structure:
status, date, context, decision, consequences, and conditions for revisiting
the decision.
